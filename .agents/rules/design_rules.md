# Reglas de Interfaz & Diseño para Smart Park

1. **PROHIBIDO EL USO DE BADGES**:
   - No usar componentes `<Badge>` ni etiquetas con aspecto de badge/pills innecesarios.
   - Usar texto directo, tipografía limpia o contenedores estructurados y claros.

2. **ACCESO AL PERFIL DE USUARIO**:
   - El perfil de usuario se abre **exclusivamente** haciendo clic en el icono / botón de usuario ubicado en la barra superior (Navbar).
   - No agregar "Mi Perfil" en la barra lateral (Sidebar) ni como pestaña repetitiva.

3. **ESTRICTO APEGO A LOS REQUERIMIENTOS**:
   - No agregar servicios o características extras no solicitadas (ej. Carga EV, Lavado, PMR badges, etc.).
